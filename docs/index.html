    LLM review settings

    Merge proposal tables can ask an LLM what a reviewer should watch out for. A review runs only when you ask for one, from this browser, with your own API key, and is kept in this browser.

    Your key goes from this browser straight to the provider you pick, and nowhere else: not to GitHub, not into the dashboard's data, not into cached reviews.

    Unless you tick Remember, keys are forgotten when you close this tab. A remembered key is stored unencrypted and any page on could read it, so prefer a key with a spending limit.

    Data cached by GitHub Actions from the Launchpad API. An MP counts as open unless it is merged, rejected or superseded.
